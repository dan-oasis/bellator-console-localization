# Bellator Console 1.1.5 — русский и английский

Русская и английская локализация **Bellator Console 1.1.5** (`斗战者控制台`), включая утилиту калибровки цвета **ApplyIcc**.

[Скачать RU / EN](https://github.com/dan-oasis/bellator-console-localization/raw/refs/heads/main/dist/BellatorConsole_1.1.5_RU_EN.zip) · [English](README.md) · [SHA-256](https://github.com/dan-oasis/bellator-console-localization/blob/main/dist/SHA256SUMS)

## Возможности

- Перевод главного окна, настроек, режимов производительности, управления вентиляторами, подсветки, диалогов и подписей экспорта.
- Перевод интерфейса и сообщений калибровки цвета.
- Выбор русского или английского языка при установке.
- Смена языка, резервное копирование и восстановление оригиналов.
- Проверка SHA-256 устанавливаемых файлов, текущих файлов и резервных копий.

## Требования

Windows, PowerShell 5.1 или новее, права администратора и установленная оригинальная Bellator Console 1.1.5. Пакет содержит только локализацию, без оригинального установщика и драйверов. Неизвестные сборки программы не поддерживаются.

## Установка

1. Полностью распакуйте ZIP в папку.
2. Закройте Bellator Console, включая значок в трее, и ApplyIcc.
3. Запустите **Install.cmd от имени администратора**.
4. Выберите **Русский** или **English**.
5. Укажите папку программы с файлом `斗战者控制台.exe`.
6. Запустите Bellator Console обычным ярлыком.

Для смены языка повторно запустите **Install.cmd**. Для переключения необходимы резервные копии оригиналов.

## Восстановление

Закройте оба приложения и запустите **Restore.cmd** от имени администратора. Будут восстановлены оба оригинальных файла. Выбор языка определяет язык сообщений установщика.

| Файл | Резервная копия |
| --- | --- |
| `斗战者控制台.dll` | `斗战者控制台.dll.before-russian` |
| `ApplyIcc/ApplyIcc.exe` | `ApplyIcc/ApplyIcc.exe.before-russian` |

Сохраняйте резервные копии. Суффикс `.before-russian` используется для обоих языков. До замены проверяются резервные копии и оба целевых файла. При ошибке установщик пытается вернуть состояние до начала установки.

## Состав и проверки

Пакет заменяет два файла из таблицы. Основной EXE, драйверы, службы, ICC-профили и настройки приложения не заменяются. Подписи производителя на локализованных файлах не сохраняются. Часть технических сообщений и названий элементов ОС остаётся на исходном языке.

Автоматические проверки охватывают структуру файлов, ссылки на строки, **472 тела методов**, установку, смену языка и восстановление. Проверки выполняются в Windows и Linux. Они не подтверждают работу переключения GPU, вентиляторов, результаты калибровки и отображение интерфейса на конкретных моделях ноутбуков.

## Сборка и тестирование

Python 3.10 или новее; сторонние Python-пакеты не требуются. Команды выполняются из корня репозитория:

```sh
python src/build_english.py
python src/package.py
python -m unittest discover -s tests -p 'test_*.py' -v
```

Тест установщика в Windows:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests\test-installer.ps1
```

Тест использует временные файлы и не запускает приложение. Словарь перевода находится в `locales/en.json`, результаты проверки бинарных файлов — в `docs/build-report.json`.

Установка из командной строки:

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Install.ps1 -Action Install -Language ru -Folder 'C:\Путь\К\Bellator Console'
```

`-Language en` устанавливает английский язык, `-Action Restore` восстанавливает оригинальные файлы. CMD-файлы не изменяют глобальную политику выполнения PowerShell.
