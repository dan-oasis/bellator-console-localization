# Bellator Console 1.1.5 — русский и английский

Неофициальная локализация **Bellator Console 1.1.5** (`斗战者控制台`), включая отдельное окно калибровки цвета **ApplyIcc**.

[**Скачать установочный пакет RU / EN**](dist/BellatorConsole_1.1.5_RU_EN.zip?raw=true) · [English](README.md) · [SHA-256](dist/SHA256SUMS)

## Установка и выбор языка

1. Сначала установите оригинальную программу производителя. Этот пакет содержит только локализацию.
2. Скачайте ZIP и **распакуйте целиком в новую папку**.
3. Полностью закройте Bellator Console, включая значок в трее, и окно калибровки.
4. Запустите **Install.cmd от имени администратора**.
5. В окне выбора нажмите **Русский** или **English**.
6. Укажите основную папку установленной программы с файлом `斗战者控制台.exe`. После успешной установки запускайте программу обычным ярлыком.

Чтобы сменить язык, снова запустите **Install.cmd** и выберите другой язык. Предыдущие русские редакции 1–5 поддерживаются, если сохранены резервные копии оригиналов.

Для возврата оригинальных файлов запустите **Restore.cmd** от имени администратора при закрытых приложениях. В этом случае выбор языка влияет только на сообщения установщика.

Нужна Windows с PowerShell 5.1 или новее. Можно также указать параметры явно:

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Install.ps1 -Action Install -Language ru -Folder 'C:\Путь\К\Bellator Console'
```

`-Language en` устанавливает английский. `-Action Restore` возвращает оригиналы. CMD-файлы не изменяют глобальную политику выполнения PowerShell.

## Резервные копии и совместимость

Меняются только интерфейсная `斗战者控制台.dll` и `ApplyIcc/ApplyIcc.exe`. Основной EXE, драйверы, службы, ICC-профили и настройки не входят в пакет изменений.

Оригиналы сохраняются рядом с файлами:

- `斗战者控制台.dll.before-russian`
- `ApplyIcc/ApplyIcc.exe.before-russian`

Суффикс `.before-russian` сохранён для совместимости и при английской установке. **Не удаляйте эти копии.** Установщик проверяет их SHA-256. Он отказывается менять неизвестные сборки, проверяет оба целевых файла до начала замены и пытается вернуть предыдущее состояние, если одна из замен завершается ошибкой.

Полный оригинальный установщик и оригинальные бинарные файлы производителя в репозиторий не включены. В нём находятся переведённые файлы приложения, скрипты и словарь перевода. Подписи производителя на изменённых файлах не сохраняются.

## Что переведено и проверено

Главное окно, режимы, переключатели, управление вентиляторами, подсветка, диалоги, подписи экспорта и окно калибровки. Сохранены согласованные подписи **Ghz**, **°C**, **CPU's**, **CPU/GPU**, **system**. В рамке числа ядер остаётся только динамическое число.

Русские файлы сохранены из присланной редакции 5 без изменений. Английские созданы из них. Структурная проверка охватывает PE/.NET, записи BAML, смещения словарей, ссылки на строки и **472 тела методов**: внутри методов допускается изменение только операндов ссылок на переведённые строки. Строки поиска окон и элементов Windows в ApplyIcc сохранены. Часть технических сообщений производителя может остаться на исходном языке.

**Новый английский интерфейс и установщик ещё требуют проверки на вашем Windows-ноутбуке.** Структурные проверки и тесты на временных файлах не подтверждают работу переключения GPU, вентиляторов или калибровки. Предыдущие русские редакции проверялись визуально по присланным скриншотам.

Исходники сборки — в `src/`, словарь — `locales/en.json`, отчёт — [docs/build-report.json](docs/build-report.json). Команды сборки и тестирования приведены в [English README](README.md#build-and-test).
